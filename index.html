Зачем нужны компьютерные сети?

Компьютерная сеть — это группа устройств (компьютеры, смартфоны, принтеры, камеры и т.д.), которые соединены между собой для обмена информацией и совместного использования ресурсов (например, файлов или интернета).

Исторический экскурс: Как раньше подключались к интернету?

📞

Dial-up (коммутируемое подключение)

  • Компьютер подключался к интернету через модем, который набирал телефонный номер провайдера
  • Скорость была очень низкой (обычно 56 Кбит/с)
  • Во время использования интернета телефонная линия была занята
🔌

ADSL (поздняя технология)

  • Позволяла использовать интернет и телефон одновременно
  • Скорость была выше (до нескольких Мбит/с)
  • Работала через разделение частот

Сетевое оборудование

Активное сетевое оборудование

Требует питания, обрабатывает и управляет данными — это «мозг» и «сердце» сети.

🔄

Маршрутизатор (роутер)

Указывает, какому устройству куда отправлять данные, соединяет разные сети

🔀

Коммутатор (свитч)

Объединяет устройства в локальной сети, передаёт данные только нужному получателю

📡

Точка доступа

Преобразует проводную сеть в Wi-Fi, создаёт зону беспроводного покрытия

📶

Модем

Преобразует цифровой сигнал компьютера в аналоговый для передачи

🎯

Сетевая карта (NIC)

Устанавливается в устройства для подключения к сети

📈

Репитер

Усиливает сигнал, расширяет дальность сети

🚦

Концентратор (хаб)

Передаёт входящий сигнал на все порты сразу (устарел)

🛡️

Межсетевой экран

Фильтрует трафик, защищает сеть от несанкционированного доступа

🔄

Медиаконвертер

Преобразует один тип кабеля в другой

🖥️

Серверы

Мощные компьютеры для хранения данных и предоставления сервисов

Пассивное сетевое оборудование

Не требует питания, не обрабатывает данные — это «скелет» сети, обеспечивает физическую передачу сигналов.

🔌 Кабели

  • Витая пара (UTP/STP): основной кабель для локальных сетей
  • Оптоволокно: для передачи данных на большие расстояния
  • Коаксиальный кабель: устарел для сетей

🔗 Разъёмы и коннекторы

Соединяют кабели с устройствами (RJ-45 для витой пары, LC/SC для оптоволокна)

📋 Патч-панели

Организуют подключение кабелей в серверных, упрощают обслуживание

🔌 Патч-корды

Короткие кабели с разъёмами, соединяют патч-панели и устройства

🏠 Информационные розетки

Удобные точки подключения в стенах для устройств

🗄️ Монтажные шкафы и стойки

Для аккуратного размещения сетевого оборудования

📦 Кабель-каналы, лотки, короба

Укладывают и защищают кабели в зданиях

Проводные сети: Ethernet

Что такое стандарт Ethernet?

Ethernet — это стандарт, по которому большинство современных проводных сетей обмениваются данными.

🔧 Стандарт Ethernet

Свод правил, описывающих, как устройства должны «разговаривать» друг с другом по кабелям

🔌 Ethernet-кабель

Физическая проводка (например, «витая пара» Cat5e/Cat6), по которой бегут данные

📦 Структура Ethernet кадра

Кадр (Frame) — это как посылка, с которой работают почтовые службы

Компоненты кадра:

  • Преамбула — специальная начальная последовательность битов для синхронизации
  • MAC-адреса — уникальные адреса отправителя и получателя
  • Тип/Длина — показывает, какой протокол или сколько данных внутри кадра
  • Полезная нагрузка — собственно, те данные, которые передаются
  • Трейлер (FCS) — контрольная сумма для проверки целостности

Беспроводные сети: Wi-Fi

Что такое Wi-Fi?

Wi-Fi — это технология, которая позволяет устройствам обмениваться данными без проводов через радиоволны.

📅 История Wi-Fi

1999 Первый массовый стандарт 802.11b
2003 802.11g — улучшенная скорость
2009 802.11n — MIMO технология
2013 802.11ac — гигабитные скорости
2019 802.11ax (Wi-Fi 6) — новая эра

📡 Как работает Wi-Fi?

📡

Роутер

Мини-радиостанция у вас дома, передает данные по радиоволнам

📱

Устройства

Радиоприемники, которые ловят сигналы и отвечают роутеру

🌊

Радиоволны

Невидимые волны, которые окружают нас и переносят данные

Роутер как центральный элемент домашней сети

🏠 Роутер — главный в домашней сети

Роутер совмещает в себе несколько функций:

📡

Точка доступа

Создает беспроводную сеть, раздает Wi-Fi

🔄

Маршрутизатор

Распределяет данные между интернетом и устройствами дома

🏷️

DHCP-сервер

Выдает каждому устройству уникальный IP-адрес

🏷️ Что такое DHCP?

DHCP (Dynamic Host Configuration Protocol) — это автоматическая выдача IP-адресов.

Процесс получения IP-адреса:

1
Устройство подключается к сети
2
DHCP-сервер выдает свободный IP-адрес
3
Устройство получает сетевые настройки
4
Устройство может работать в сети

Адресация в сетях

🏷️ MAC-адрес

MAC-адрес — уникальный номер сетевой карты (например, 00:1A:2B:3C:4D:5E), нужен только внутри локальной сети.

🌐 IP-адрес и его виды

IP-адрес — это уникальный номер устройства в сети, например, 192.168.1.5.

🔓 Белые (публичные) IP-адреса

Адреса, которые видны в интернете. По ним любой может "достучаться" до устройства из любой точки мира.

8.8.8.8 5.255.255.5

🔒 Серые (частные, приватные) IP-адреса

Адреса для использования внутри локальных сетей. В интернете не видны.

10.0.0.0 – 10.255.255.255
172.16.0.0 – 172.31.255.255
192.168.0.0 – 192.168.255.255

🔄 NAT (Network Address Translation)

NAT — роутер позволяет всем устройствам в доме выходить в интернет через один внешний IP.

Внутренняя сеть

192.168.1.100
192.168.1.101
192.168.1.102
🔄

🚪 Порты в сети

Порт — это числовой идентификатор (от 0 до 65535), который помогает компьютеру понять, какому приложению отдать входящие данные.

🏛️ Системные порты (0–1023)

Зарезервированы для стандартных сервисов

22 - SSH 80 - HTTP 443 - HTTPS 53 - DNS

👤 Пользовательские порты (1024–49151)

Используются приложениями, но не закреплены жестко

🔄 Динамические порты (49152–65535)

Применяются для временных клиентских соединений

Протокол разрешения адресов (ARP)

🔍 ARP — "телефонный справочник" локальной сети

ARP (Address Resolution Protocol) нужен для автоматического перевода IP-адреса в MAC-адрес в пределах одной локальной сети.

DNS

Переводит доменные имена в IP-адреса

google.com → 142.250.74.206

ARP

Переводит IP-адреса в MAC-адреса

192.168.1.10 → 00:AA:BB:CC:DD:EE

⚙️ Как компьютер определяет, своя ли подсеть?

Процесс проверки:

  1. Берется свой IP и маска подсети
  2. Берется IP назначения
  3. Применяется логическое И (AND) к обоим IP с маской
  4. Если результат одинаков — цель в той же подсети
  5. Если нет — пакет отправляется через шлюз

Пример расчета:

IP: 192.168.1.5
Маска: 255.255.255.0
Цель: 192.168.1.10
192.168.1.5 & 255.255.255.0 = 192.168.1.0
192.168.1.10 & 255.255.255.0 = 192.168.1.0
Совпало — цель в той же подсети

DNS (Domain Name System)

🌐 Система доменных имён

DNS — это система, которая переводит понятные человеку доменные имена (например, yandex.ru, google.com) в IP-адреса, которые понятны компьютерам.

🔍 Процесс резолвинга DNS

1

Ввод адреса

Вы вводите в браузере vk.com

2

Проверка кэша

Система проверяет локальный кэш

3

Запрос к DNS-серверу

Обращение к DNS-серверу провайдера

4

Рекурсивный поиск

Поиск через корневые и авторитетные серверы

5

Получение ответа

IP-адрес возвращается и сохраняется в кэше

📋 Основные типы DNS-записей

A-запись

Связывает доменное имя с IPv4-адресом

example.com. IN A 192.0.2.1

AAAA-запись

Связывает доменное имя с IPv6-адресом

example.com. IN AAAA 2001:db8::1

CNAME

Перенаправляет один домен на другой

www.example.com. IN CNAME example.com.

MX-запись

Указывает почтовые серверы для домена

example.com. IN MX 10 mail.example.com.

TXT-запись

Хранит текстовую информацию (SPF, DKIM, подтверждения)

example.com. IN TXT "v=spf1 ip4:192.168.1.1 -all"

Передача данных: Пример "от браузера до сайта"

Диагностика и траблшутинг сетей в Linux

🔧 Диагностика физических и канальных проблем (уровни 1-2 OSI)

ip link / ifconfig

Показывают список всех сетевых интерфейсов, их состояние, MAC-адреса

ip link ifconfig

ethtool

Показывает физические параметры Ethernet-интерфейса

ethtool eth0

mii-tool

Проверяет наличие линка, поддерживаемые скорости

mii-tool eth0

🌐 Диагностика сетевого уровня (уровень 3 OSI)

ping

Проверяет доступность другого устройства, измеряет задержку

ping 8.8.8.8 ping -c 4 google.com

traceroute

Показывает маршрут до цели через интернет

traceroute google.com traceroute -n ya.ru

ip addr / ip route

Показывает IP-адреса и таблицу маршрутизации

ip addr ip route

🚪 Диагностика транспортного уровня (уровень 4 OSI)

ss / netstat

Список всех слушающих и установленных соединений

ss -tulnp netstat -tulnp

nc (netcat)

Универсальный инструмент для теста TCP/UDP соединений

nc -zv google.com 80 nc -l 12345

🌐 Диагностика верхних уровней (5-7 OSI)

curl

Отправляет HTTP/HTTPS-запросы, показывает ответ сервера

curl google.com curl -I ya.ru curl -v https://example.com

dig

Проверяет DNS-записи, узнаёт IP по имени

dig google.com dig google.com MX dig @8.8.8.8 example.com

Словарь сетевых терминов

Бит

Одна единичка информации: 0 или 1

Кадр

Упакованные данные для передачи по локальной сети; «коробка» с адресами и проверкой ошибок

Пакет

Данные для передачи между сетями, включает IP-адреса

Сегмент

Кусочек данных с номерами портов и служебной информацией (TCP/UDP)

MAC-адрес

Уникальный номер сетевой карты (например, 00:1A:2B:3C:4D:5E)

IP-адрес

Уникальный адрес устройства в сети (например, 192.168.1.10)

Протокол

Четкие правила, по которым устройства обмениваются данными

Порт

«Квартира» внутри IP-адреса для разных приложений (например, 80 — сайты)

NAT

«Подмена» адресов, когда все устройства дома выходят в интернет под одним внешним IP

Белый IP

Публичный IP-адрес, доступный из интернета

Серый IP

Частный (приватный) IP-адрес, работает только внутри локальной сети

Gateway

Шлюз по умолчанию, точка выхода из локальной сети

Визуальные схемы для запоминания

🏗️ Модель OSI

[Пользователь] ↔ [Приложение] ↔ [Представление] ↔ [Сессия] ↔ [Транспорт] ↔ [Сеть] ↔ [Канал] ↔ [Физика]
                        (7)                        (6)                    (5)              (4)            (3)          (2)        (1)

🌐 Модель TCP/IP

[Приложение] ↔ [Транспорт] ↔ [Интернет] ↔ [Доступ к сети]
                     (4)                     (3)                  (2)                        (1)

💡 Запоминалка

  • Представляй уровни как этажи в доме: каждый решает свою задачу
  • Кадр = коробка, IP-адрес = адрес дома, порт = квартира, MAC = паспорт
  • Преамбула — как стук в дверь: устройство «просыпается» и готово принимать данные
  • Трейлер/FCS — как наклейка «не вскрывать до получения»: если повреждена — выбрасываем
  • Старайся объяснять это простыми словами, будто учишь друга
